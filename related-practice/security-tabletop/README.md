# Agency security tabletop: a fictional payment-change request

An editable copy of the existing [Cirlet readiness exercise](https://aicybersecurityforinsuranceagencies.com/readiness-kit), distributed here for agency trainers and IT providers. No additional cases, live test or measured results are added. Prepared with AI assistance; Cirlet supplies optional paid help separately.

## Run it in 15 minutes

1. Assign a facilitator, reader, decision owner and note-taker. Use fictional roles and details.
2. Open [the editable exercise](tabletop-exercise-template.txt). Read the changed-payment request; discuss the trusted verification route, approval, backup and escalation. The template includes the expected process, so a facilitator can keep that portion for the comparison step.
3. Use [the after-action worksheet](after-action-template.txt) to distinguish what the team found from what remains unknown. Assign one follow-up owner and review date.
4. Compare the expected process with the discussion. Locating a procedure is not proof a technical control works.

Keep real credentials, client records, bank details and internal contact information out of GitHub and its issues. Store a completed worksheet only in an agency-approved location. Do not change live accounts, transfer money, contact a real vendor or simulate a scam on clients during this discussion.
