# Does this reply answer the whole request?

Compare one fictional request and a supplied checklist note with a deliberately flawed reply. Find the unanswered question as well as statements that lack evidence. A reply can contain correct facts and still leave part of the request unanswered.

This is original AI-assisted teaching material. The request, checklist and draft are invented; the draft was deliberately written with AI assistance for this exercise. It is **not a captured result from testing an AI tool on these inputs or a real employee message**. There are no customer records, carrier requirements, coverage decisions, measured results or real communications.

## Try it

1. Read [the source bundle](source-fictional.md), including request R81 and checklist note N81. There are two explicit questions.
2. Read [the authored draft](draft-deliberately-flawed.md). Keep the [separate authored key](AUTHORED-REVIEW.md) closed until you have finished.
3. Copy [the blank review sheet](review-blank.csv). For each check ID, cite the relevant source passage and draft passage, or state that the draft omits it. Use SUPPORTED, OMITTED or UNSUPPORTED as your assessment; write why. These labels describe this fixed teaching bundle, not whether an event happened elsewhere.
4. Check both directions: does the draft answer each source question, and does every new claim in the draft have support? Do not mark a reply ready just because its opening sentence is correct.
5. Compare with the key, then discuss what would need clarification before anyone prepares another draft. Keep any actual approval and sending outside this exercise.

You may review the files yourself or ask an approved AI tool to propose the comparison using only these fictional inputs. Keep your own review decision separate. The original exercise supplies no tool score. A [separate dated CLI observation](../../observations/2026-10-22-grok-cli/README.md) records one review response with context isolation unverified; it is not a benchmark.

## Check IDs

| ID | What to inspect |
| --- | --- |
| Q1 | Does the reply explain what the checklist covers? |
| Q2 | Does it identify the outstanding documents, or say the list is not yet known? |
| C1 | Is the claim that documents were received supported? |
| C2 | Is the claim that documents were reviewed supported? |
| C3 | Is the Friday deadline supported? |
| I1 | Does the reply correctly describe the request as information only? |

The sheet has six rows so none of these checks disappears. That row count is not a pass score. A missing answer remains missing even if every included factual statement is correct; an unsupported receipt or review claim is not fixed by a more polished tone.
