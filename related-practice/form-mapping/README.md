# Same source, two fictional intake forms

Practice mapping one made-up request into two different internal review layouts. The forms deliberately change field order and wording. They are **not carrier forms, certificates of insurance or AMS exports**.

## Try it

1. Read [the fictional source record](source-fictional.csv). Every row belongs to source `REQ-01`. Keep policy reference `000472` as text.
2. Make a working copy of [Form A](form-a-blank.csv) and [Form B](form-b-blank.csv). For every proposed entry, retain the source ID and field name. Use only the supplied record; leave unsupported values blank and explain the gap in `review_note`.
3. You may propose entries yourself or ask an approved AI tool to do so with these fictional files. Review each entry before comparing it with the [separate authored key](AUTHORED-KEY.md). No model has been run or evaluated for this exercise.
4. Check whether the layout change caused a wrong-field entry, whether missing reviewer information stayed missing, and whether the leading zeros survived. If comparing methods, include preparation, review and correction time. No timing or savings result is supplied.

All proposed-value/source-reference/review-note cells start blank. Form A asks for an assignment that the source never supplies. Form B asks who already reviewed the request; it also asks separately who made it. These are different roles.

A requested due date is a request, not a promised completion date. The received date is neither a review nor a send date. This exercise ends with proposed internal entries: no coverage decision, certificate issuance, approval, delivery, real-system access or proof of compatibility.

## Provenance and related resources

Original AI-assisted fictional teaching material prepared for Tyler Mayberry's agency review-practice collection. All names, references and dates are invented; there are no customer records. The motivating workflow observation is that an actual required layout can differ from a demonstration layout. It does not establish a vendor feature or a representative agency need.
