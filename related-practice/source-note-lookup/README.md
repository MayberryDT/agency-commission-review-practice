# Related practice: find the source note

A separate source-selection exercise related to the evidence-preservation principle in the commission practice. It adds no commission cases or financial guidance.

All people, requests and notes are fictional. The notes and review key are AI-generated teaching material, not results from testing an AI tool. No recordings or customer records.

1. Open [three source notes](call-notes-fictional.csv) and the [blank lookup index](call-note-index-blank.csv). Search the source text; retain source ID and exact excerpt with each candidate.
2. Find Riley's question about which documents to provide. Record the note ID, supplied date, request reference and supporting words.
3. Find Jordan's earlier conversation from a remembered Tuesday. Separate supplied facts from what needs checking; leave an absent date blank.
4. Find evidence that an address change was confirmed. If absent, record that limit instead of marking the request complete.
5. Compare with the [separate authored key](AUTHORED-REVIEW.md).
