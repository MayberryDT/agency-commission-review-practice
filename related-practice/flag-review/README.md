# Review a checker's flag list

Practice two different questions: how many actual errors did a checker find, and how many of its flags were useful? This is an AI-assisted fictional teaching exercise. The counts are authored assumptions, not results from an AI tool, agency records or a customer trial.

## Try it before opening the key

There are **1,000 rows**. A separate reference review identifies **10 actual errors**. The checker flags **9 of those errors** and also flags **20 rows that were already correct**.

1. Download the [two-page printable worksheet and key](review-an-ai-flag-list.pdf). Page 1 is the blank participant worksheet; page 2 is the separate worked key. It is a static PDF, not a fillable form.
2. Alternatively, copy the [blank CSV grid](blank-review.csv) into your own spreadsheet. Import it as text first if needed; blank cells are unanswered, not zero.
3. Complete each row and column total. Calculate errors found / all actual errors, then actual errors among flags / all flags. State the missed errors and unnecessary flags separately.
4. Describe how you would look for missed errors outside the flagged list. Compare your work with the [separate authored key](AUTHORED-REVIEW.md) only after trying it.

These are the same scenario and PDF published in the [original LinkedIn document](https://www.linkedin.com/feed/update/urn:li:activity:7518833468789854208/). The [complete collection ZIP](https://github.com/MayberryDT/agency-commission-review-practice/archive/refs/heads/main.zip) includes the PDF, blank CSV and key alongside the other exercises.

## What these counts leave unknown

The example does not establish error severity, review time, savings, suitability for a real agency or any tool's performance. A real evaluation needs independent reference decisions, permission to use the records, an appropriate sample and responsible reviewers. Checking only flagged rows cannot reveal missed errors. Sampled observations must not be described as complete counts.

For a different batch, record its own counts and reference-review method. With no actual errors, error detection is undefined; with no flags, precision is undefined. Do not substitute zero or perfect percentages for missing denominators.
