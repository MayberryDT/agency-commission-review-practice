# Practice sorting renewal certificate requests

An agency receives several requests around renewal time. Which messages describe the same request, which need separate review, and what has actually been sent? Use the [fictional source records](source-records.csv), the [blank review sheet](review-blank.csv) and, only after trying it, the [authored key](AUTHORED-KEY.md).

This is original AI-assisted teaching material. The names, policy references, terms, form code, messages and status notes are invented. No model was tested on these exercise inputs, no real agency data was used and no carrier requirement is represented. Keep real records out of public repositories and issues.

## Exercise rule

For this fictional exercise only, the team groups records for preparation when the policy reference, policy term and form code match. Each different named holder still needs its own review item. A message explicitly identified as a follow-up to the same unchanged request does not create another item. A missing form code or unclear relationship must be clarified before grouping. A blank request ID means the underlying request is unresolved; it does not establish a new request. This is a practice rule, not a claim about carrier forms, certificate requirements, insurance law or the right way to handle a real agency's work.

## Try it

1. Read all five request rows and the three status observations. Import the CSV with identifier and date columns set to text; automatic spreadsheet opening may strip leading zeros from identifiers such as `000041`.
2. In the blank sheet, assess each review item A–D; A and B can share a preparation group while remaining separate review items. Cite the request or status IDs, identify what can be grouped under the exercise rule, and state what remains uncertain. Do not infer a promise from a requested date.
3. For each group, record the last status the supplied notes actually establish. An internal draft or handoff is not proof a certificate was approved, issued or delivered to its recipient.
4. Compare your review with the separate authored key. A responsible person would choose the actual agency process; the key is an example of source-bound reasoning, not a score or an approval to send.

No coverage determination, certificate issuance, carrier acceptance, recipient verification, delivery, AMS integration or measured time saving is established.
