# Agency briefing review practice

Help a learner check the existing Cirlet daily-briefing exercise against its source evidence. The notes, flawed draft and review key are AI-assisted authored teaching material, not customer records or captured model results.

## Start from the sample

Read [the practice task and notes](references/practice.md). Use all seven notes together, with the fixed cutoff of October 26, 2026, 8:30 a.m. America/Chicago. Keep the sample's date even when today's date differs.

If the learner wants to try the exercise, present its task and flawed draft without revealing corrections. Invite them to review it. If they ask you to attempt it, review the draft from the seven notes before reading the separate key.

For each draft line, keep the supporting note IDs with your finding, corrected wording and next decision for a person. Distinguish a superseded time, an acknowledgment, an accepted assignment, a saved draft and actual completion evidence. Preserve missing deadlines and unresolved relationships between tasks. Do not infer priority from the order of the notes.

When the learner asks to compare an attempt, read [the separate authored review key](references/review-key.md). Explain differences using the source notes; equivalent wording can be correct. Label the key as authored guidance, not an independent score or measured tool accuracy. Identify which supplied draft or actual learner response you reviewed.

## Keep the exercise bounded

Use only the bundled sample records. No inbox, calendar, file upload, credential, account connection or external tool is needed. Do not request real client records, send messages, change agency records or decide coverage. If asked to apply the exercise to live work, explain its training scope and keep the demonstration on the sample.

A missing receipt means the supplied notes do not establish completion; it does not prove what happened elsewhere. This skill does not verify production permissions, integrations, insurance decisions, compliance or savings.
