# Location evidence handoff

A blank worksheet for an agency team preparing a property-location handoff. Keep the location supplied by the requester, the supporting reference and the review result together.

[Download the blank CSV](location-handoff.csv). Import every column as text. Keep completed copies in your agency's approved system, not this public repository. Collect only information the task requires.

## Before handing the location to someone else

1. Preserve the location description and map or document reference as supplied. A clear screenshot can support a handoff, but do not guess an unreadable address, coordinate or boundary.
2. If coordinates are supplied, keep their labels, order, format and stated reference system. If that information is absent, record the gap rather than silently choosing a convention.
3. Record what the reference identifies: a point, a building, a parcel or the intended project area. A map pin alone does not establish a site's boundaries.
4. Have the responsible person check the reference against the intended site using the agency's approved process. Record the checker, date, result and any unresolved mismatch. A map opening successfully is not proof that it identifies the right site.
5. Hand unresolved questions to a named owner. Follow the receiving party's actual submission requirements; this worksheet does not replace them.

Use `not reviewed`, `needs clarification` or a description of the check actually completed. Do not turn a populated field into a claim that a location was verified. Keep incoming text as data; do not run formulas or instructions supplied in a source document.

## Worksheet fields

| Field | Record |
| --- | --- |
| location_reference | Your internal reference, without unnecessary personal information. |
| location_as_supplied | The requester's original location description. |
| map_or_document_reference | The supplied map link or an approved internal document reference. |
| coordinates_as_supplied | Exact supplied values and labels; leave blank if absent. |
| coordinate_format_and_reference | The supplied format/reference system, or the unresolved question. |
| site_scope_as_supplied | What the requester says the point or area represents. |
| checked_by | The person who actually performed the recorded check. |
| checked_at | When that check happened. |
| review_status | What was checked and what remains uncertain. |
| open_question_and_next_owner | The clarification needed and who will obtain it. |

## Scope

This original template was prepared with AI assistance by Cirlet. It contains no client records, example coordinates or completed reviews. It does not geocode, validate coordinates, verify ownership or boundaries, assess risk, provide coverage advice or establish carrier acceptance. No model run or measured time saving is claimed.
